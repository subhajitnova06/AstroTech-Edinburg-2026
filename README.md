# AstroTech Edinburgh 2026 — week 1 exercises

Short Python exercises from the University of Edinburgh **AstroTech** workshop (week 1).

These are **schematic / toy models**, not data analysis of a real telescope or of Andromeda. They are here to show basic NumPy + Matplotlib for astronomy geometry and atmospheric windows.

## Contents

| Folder | What it actually is |
| :--- | :--- |
| `Transmission-analysis/` | Schematic plot of Earth's *optical and infrared* windows. Radio is **not** in the 10–20 μm range. |
| `Distance-analysis/` | Toy scaling: angular size \(\propto 1/d\), flux \(\propto 1/d^2\). Not measured Andromeda photometry. |

```bash
pip install -r requirements.txt
python Transmission-analysis/Transmission-analysis.py
python Distance-analysis/Distance-analysis.py
```

Spelling: the workshop is **Edinburgh**, not Edinburg. The GitHub repo name was left as created.
