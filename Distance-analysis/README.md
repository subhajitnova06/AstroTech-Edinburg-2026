# Toy scaling of angular size and flux with distance

For a source of fixed physical size and luminosity:

- angular size \(\theta \propto 1/d\)
- flux \(F \propto 1/d^2\)

This script plots those two laws, normalised to the nearest point. It is **not** a measurement of Andromeda (M31). The workshop used Andromeda as the example object; the numbers here are relative distance factors \(1, 2, 5, 10, 20\).

```bash
python Distance-analysis.py
```
