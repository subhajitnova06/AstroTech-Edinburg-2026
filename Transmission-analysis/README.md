# Atmospheric transmission windows

Ground-based astronomy is limited by Earth's atmosphere. This script plots the main optical and infrared windows.

- **0.3–0.9 μm** — optical window
- **~1.5–2.4 μm, 3–5 μm, 8–13 μm** — infrared windows
- **10–20 μm** is mid-infrared; radio windows start at millimetre-to-metre wavelengths
- UV and X-rays are absorbed at the ground, so those telescopes are space-based

```bash
python Transmission-analysis.py
```
